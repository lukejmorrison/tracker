# Atlas data

Compiled TypeScript. No scraper.

| File | Role |
| --- | --- |
| `countries.ts` | Access, volume, restrictions, snapshot, gap |
| `proceedings.ts` | Court / regulator / bill docket |
| `menu.ts` | Named duty lists and volume splits |
| `filters.ts` | Open-source algorithm filters |
| `types.ts` | Shared types |

How to add a row: [docs/DATA.md](../../docs/DATA.md).
